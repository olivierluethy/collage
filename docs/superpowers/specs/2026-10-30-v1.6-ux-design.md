# v1.6 — UX overhaul ("maximal unkompliziert")

Status: approved in chat, 2026-10-30. Visual system stays **Darkroom** (`docs/STYLEGUIDE.md`);
no new colour or font tokens. Flows may be regrouped; every existing feature stays reachable.

## 1. Onboarding & first launch
- Three pages. Pages 1–2 show a live mini-collage (drawn from layout polygons, no assets) instead of
  an icon; page 2 animates two cells swapping (static under reduced motion).
- Page 1 carries a language chip (top-left) that opens the language picker.
- Page 3 "Los geht's": privacy note + primary **Fotos wählen** (requests gallery access, then starts
  the new-collage flow) and secondary **Erst umschauen** (Home, no permission).
- `onboardingDone` is set whenever onboarding is left.

## 2. Home & navigation
- NavigationBar with four tabs: Collagen · Vorlagen · Entdecken · Mehr. App bar shows only the title.
- "Neue Collage" FAB on Collagen and Entdecken opens the **New collage sheet**: Fotos wählen
  (primary) · Mit Vorlage starten (switches to Vorlagen) · KI-Vorschlag (AiScreen).
- Collage cards get a visible ⋯ menu (long-press kept). Delete moves to trash with an Undo snackbar.
- Empty library: two actions (create / browse templates).
- **Mehr** tab = the former InfoScreen, regrouped: Bibliothek (Fotobücher, Papierkorb) · Sichern
  (Backup/Restore) · Einstellungen (Sprache, Darstellung) · Über (About, Privacy, Terms, Version).

## 3. Creation flow
- New collage → photo picker → **editor directly** with an auto layout (`LayoutTemplates.forCount`)
  at 1:1. Shared helper with `openPhotosAsCollage`. `LayoutPickerScreen` is removed.
- Picker: button "Collage mit N Fotos erstellen"; one-time hint about tap order.
- Editor Layout panel gains a **Eigenes Layout** tile (opens `CustomTemplateScreen`); ratios show
  their name plus spec chip.

## 4. Editor
- Leaving the editor (back, app paused) **auto-saves** the draft (skipped when empty).
- Title in the app bar, tap to rename. Primary action **Fertig** opens the export sheet.
  Overflow: Als Vorlage speichern · Einführung zeigen.
- Tool rail: 5 tools — Fotos · Layout · Stil · Hinzufügen · Ebenen, evenly spaced, no scrolling.
  - Stil = one panel with segmented Rahmen / Hintergrund / Filter (existing panels).
  - Hinzufügen = grid of Text, Sticker, Emoji, Formen, GIF (Giphy only), Zeichnen; each panel has a
    back arrow to the grid.
- Context bar: max. 4 visible actions; flips, forward/back, straighten move into a **Mehr** sheet.
- `CoachTour` widget (styleguide coach-mark) replaces the 7 s snackbar: photo slot → swap/gestures →
  Layout tool. Shown once (`coachSeen('editor_tour')`), replayable from the overflow menu.

## 5. Secondary screens & polish
- Export sheet: plain-language hint per size; primary "In Galerie speichern" saves straight away,
  then opens the result screen in the saved state.
- Result screen: confirmation + preview, primary Teilen, secondary Weiter bearbeiten / Fertig;
  profile grid & carousel grouped under an expandable "Für Instagram".
- Shared helpers in `lib/widgets/ui.dart`: `showAppSnack` (status icon, ≤1 amber action) and
  `confirmDestructive` (danger action named by what it does).
- Tooltips/semantics on icon-only buttons; consistent empty states.
- New patterns documented in `docs/STYLEGUIDE.md` §9c.

Out of scope: new features, new tokens, changes to export logic, models or services.
Per the user's instruction, no new tests are written or run in this iteration.
